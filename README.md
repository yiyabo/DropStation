# DropStation · 文件中转站

一个 macOS 菜单栏小工具：在任何应用里拖拽文件时**快速晃动鼠标**，即可把文件暂存到悬浮的"中转站"面板里，之后随时再拖出去。适合在多个窗口、应用之间搬运文件的场景，免去了来回切换、平铺窗口的麻烦。

## 功能

- **晃动暂存**：拖拽文件时快速左右（或上下）晃动鼠标（约 1.2 秒内反向 3 次），中转站面板就会出现在鼠标旁边，直接把手里拖着的文件投进去。
- **拖入暂存**：也可以把文件直接拖到面板上。
- **拖出发送**：按住面板里的文件行即可重新发起拖拽，把文件投到任何地方；文件可重复拖出，投到多处。
- **位置记忆**：面板首次出现后就固定在同一位置，不会每次乱跑；拔掉显示器等导致位置失效时会自动重新就近定位。
- **Esc / Cmd+W 关闭**：只要鼠标悬停在面板上，即使焦点在其他应用也能快捷关闭（关闭会清空暂存列表）。

## 环境要求

- macOS 13+
- **辅助功能权限**（系统设置 → 隐私与安全性 → 辅助功能）：晃动检测与全局快捷键依赖它。未授权时菜单栏菜单里会出现"需要辅助功能权限…"引导项。

## 构建

```bash
./build-app.sh
```

脚本会完成编译（`swift build -c release`）、生成应用图标（需要 `pip install Pillow`）、组装并签名 `DropStation.app`。构建完成后直接打开 `DropStation.app` 即可，也可以拖进"应用程序"目录。

> 提示：默认使用 ad-hoc 签名，每次重新构建后 macOS 会视为新程序，需要在辅助功能里重新勾选。若在"钥匙串访问 → 证书助理"里创建一个名为 `DropStation Development` 的代码签名证书，脚本会自动使用它，重新构建后授权保持有效。

也可以只用 Swift Package Manager 直接构建二进制：

```bash
swift build -c release
```

## 实现说明

纯 AppKit 实现，无第三方依赖（图标生成脚本依赖 Pillow）。

| 模块 | 职责 |
| --- | --- |
| `ShakeDetector` | 监听全局/本地鼠标事件，基于轴向归类 + 方向反转计数的晃动识别；通过拖拽粘贴板 `changeCount` 基线区分"正在拖拽"与"粘贴板残留" |
| `StationWindowController` / `StationPanel` | 无边框 `nonactivatingPanel`，浮动层级、跨空间显示、不抢焦点，含出现动画与屏幕边界约束 |
| `StationView` | 全手绘 UI（文件列表、hover 高亮、空状态投放区），同时作为拖入目的地与拖出 `NSDraggingSource` |
| `KeyboardShortcutMonitor` | `CGEventTap` 全局快捷键（仅当鼠标悬停于面板时拦截 Esc / Cmd+W），无权限自动重试、超时自动恢复 |
